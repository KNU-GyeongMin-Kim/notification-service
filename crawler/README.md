# 크롤러 (crawler)

학과 게시판에서 공지사항을 주기적으로 가져와 데이터베이스에 저장하는 모듈입니다.

- 담당: 김문수
- 브랜치: `feature/crawler`

## 하는 일

1. 학과 게시판 목록 페이지에서 글번호, 제목, 날짜, 링크를 가져옵니다.
2. 데이터베이스에 저장된 마지막 글번호와 비교해 새 글만 골라냅니다.
3. 새 글의 상세 페이지에서 본문을 가져옵니다.
4. 데이터베이스에 저장합니다. 이미 있는 글은 다시 저장하지 않습니다.
5. 저장한 새 공지 목록을 서버에 넘깁니다. 서버는 이 목록으로 요약과 알림을 처리합니다.

## 시스템 안에서의 위치

```
학과 게시판 ──(크롤링)──> 크롤러 ──(저장)──> 데이터베이스
                            │
                            └──(새 공지 목록)──> 서버 ──> 요약 ──> 알림
```

서버의 스케줄러가 10분마다 크롤러를 실행합니다.

## 넘겨주는 데이터 형식

공지 하나를 아래와 같은 사전(dict) 형태로 만듭니다. 이름은 데이터베이스 공지 테이블과 맞춥니다.

```python
{
    "post_no": 1234,                 # 게시판 글번호 (새 글 판별 기준)
    "title": "2026학년도 2학기 국가장학금 신청 안내",
    "date": "2026-11-13",            # 게시일
    "url": "https://...",            # 원문 링크
    "content": "본문 내용...",        # 본문이 없으면 빈 문자열
    "collected_at": "2026-11-13 14:30:00",  # 수집 시각
}
```

- `beautifulsoup4`: 페이지에서 원하는 부분 찾기

## 주의 사항

- 게시판 이용약관과 `robots.txt`를 확인하고 지킵니다.
- 요청 사이에 1초 이상 간격을 둡니다.
- 첫 실행 때는 기존 글을 저장만 하고 알림은 보내지 않습니다. 기존 글 알림이 한꺼번에 발송되는 것을 막기 위해서입니다.
- 본문 없이 이미지나 첨부파일만 있는 공지는 본문을 빈 문자열로 저장하고, 원문 링크로 안내합니다.
- 게시판 접속에 실패하면 기록만 남기고 다음 주기에 다시 시도합니다.
