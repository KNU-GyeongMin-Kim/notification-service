# 학과 공지사항 통합 관리 및 알림 서비스

학과 홈페이지에 흩어져 있는 공지사항을 한곳에서 확인하고, 필요한 소식을 놓치지 않도록 돕는 서비스입니다.

새 공지사항이 등록되면 SMS 또는 이메일로 알림을 받을 수 있도록 하고, AI를 활용한 자동 분류·요약과 자연어 검색 기능을 제공하는 것을 목표로 합니다.

> 이 프로젝트는 1학년 팀 프로젝트로 진행 중이며, 아래 기능과 기술은 구현 및 검토 과정에서 변경될 수 있습니다.

## 주요 기능

- 학과 홈페이지의 공지사항을 자동으로 수집해 통합 관리
- 새 공지사항 등록 시 SMS 및 이메일 알림 제공
- 관심 키워드를 설정해 관련 공지사항 알림 받기
- AI 기반 공지사항 자동 분류 및 요약
- 자연어로 원하는 공지사항 검색
- 신청 기간, 지원 대상, 제출 서류 등 주요 정보 추출

## 프로그램 구성

| 구성 요소 | 역할 |
| --- | --- |
| **Frontend** | 공지사항을 확인하고 서비스를 이용하는 웹 페이지 |
| **Backend** | 프론트엔드, 데이터베이스 및 서비스 기능을 연결하는 서버 |
| **Database** | 공지사항과 사용자 정보를 저장하고 관리 |
| **Crawler** | 학과 홈페이지에서 새 공지사항을 수집 |
| **LLM** | 공지사항 분류·요약 및 자연어 검색 지원 |
| **Notification** | SMS 및 이메일 알림 전송 |
