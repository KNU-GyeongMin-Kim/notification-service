# UI 구현 계획 — 김원중

## 개요

JavaScript와 React를 사용해 공지사항을 확인하고 알림을 관리하는 웹 UI를 구현합니다. 모든 화면은 공통 헤더와 푸터를 사용하고, 페이지 이동 시에는 가운데 콘텐츠만 바뀌도록 구성합니다.

## 페이지 및 라우팅

총 5개 페이지를 React Router로 연결합니다.

1. 메인
2. 공지 목록
3. 공지 상세
4. 로그인
5. 알림 설정

- 공통 `Layout` 안에 `Header`, 페이지 콘텐츠, `Footer`를 배치합니다.
- 메뉴를 클릭하면 전체 페이지를 다시 불러오지 않고 필요한 콘텐츠만 교체합니다.
- 로그인이 필요한 페이지는 인증 상태를 확인하고, 비로그인 사용자는 로그인 페이지로 안내합니다.

## 공지 목록

공지사항을 검색하고 상세 내용을 열람하기 위한 화면입니다.

- 검색창
- 카테고리 탭: 전체, 학사, 장학, 취업, 행사, 대학원
- 공지 카드 목록
- 페이지 이동 버튼
- 카드에는 분류, 게시일, 제목과 신청 마감일 등 주요 정보를 표시합니다.
- 데이터를 불러오는 동안 로딩 상태를 표시하고, 결과가 없으면 “등록된 공지가 없습니다”를 표시합니다.

## 공지 상세

- 상단에 제목, 작성일, 카테고리, 원문 게시판 이름을 표시합니다.
- AI 요약을 핵심 정보 카드로 보여줍니다.
- 하단에 공지 원문과 첨부파일 링크를 제공합니다.

## 알림

- 새 공지와 마감일이 가까운 공지를 사용자에게 알립니다.
- 새 알림은 화면 오른쪽 위에 몇 초 동안 팝업으로 표시합니다.
- 헤더의 종 아이콘에 읽지 않은 알림 수를 표시합니다.
- 종 아이콘을 누르면 알림 목록을 열고, 알림을 누르면 해당 공지 상세로 이동하면서 읽음 처리합니다.

## 기술

- 언어: JavaScript
- UI: React
- 라우팅: React Router
